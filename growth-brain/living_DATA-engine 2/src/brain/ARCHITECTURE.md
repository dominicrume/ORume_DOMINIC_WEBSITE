## 1. Module Purpose & Boundary Contract
The `src/brain/` module houses the **Autonomous Decision Engine** (`growthAdvisor.js` and `learner.js`). It transforms raw audience traffic metrics into actionable diagnostic advice, identifying funnel friction and prescribing strategic monetization actions across the Rume Dominic / Vorem ascension ladder.

> **Grounding Rule (Root #11):** The AI Growth Brain MUST ground its reasoning in real SQL aggregations (`DB.growth.byCategory.all()`, `DB.growth.bySource.all()`). It is strictly prohibited from generating generic marketing advice that does not reference actual channel conversion rates, visitor volumes, or bottleneck percentages.

## 3. Heuristic Offline Fallback Architecture (Root #7 & #9)
To guarantee 24/7 continuous operation without system lags or crashes when LLM endpoints (`@anthropic-ai/sdk`) experience rate-limits, network timeouts, or missing API keys, `growthAdvisor.js` implements a deterministic **Offline Heuristic Analysis Engine**:

1. **Top Channel Identification:** Sorts categories by `total_visitors` descending to select the primary traffic stream.
2. **Bottleneck Diagnosis:**
   - If `total_visitors === 0`, flags pipeline starvation.
   - If `conversion_rate === 0%`, diagnoses immediate lead magnet / opt-in friction on the primary channel.
3. **Structured Recommendation Generation:** Generates 4 prioritized, data-grounded recommendation objects matching exact JSON schemas (`action`, `rationale`, `expected_impact`, `priority`, `target_tier`, `channel`).

---

## 4. Audit Trail & Decision Persistence (Root #8)
Every diagnostic cycle is recorded persistently in SQLite:
- `DB.insights.record.run(...)` stores the complete diagnostic payload in `growth_insights`.
- `DB.decisions.record.run(...)` logs stage-by-stage reasoning in `agent_decisions` for retrospective audit.
